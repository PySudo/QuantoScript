# QuantoScript Documentation

The complete language reference now lives in **[The QuantoScript Guide](docs/guide/README.md)**.

It is organised as a set of linked chapters — syntax, types, operators, strings,
lists, maps, control flow, functions, lambdas, classes, errors, imports, the
standard library, built-in functions, execution engines, the CLI, the package
manager, and known limits. Every chapter links to the one before and the one
after it, so it reads from start to finish like a book.
